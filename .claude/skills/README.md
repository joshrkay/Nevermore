# Matt Pocock's skills

These skills are vendored from https://github.com/mattpocock/skills (MIT, see `LICENSE`)
at commit `5beb35b040e3de97e54fa9e386d7e42d15c295c2`. They are the 27 skills in that repo's
`.claude-plugin/plugin.json` set. `misc/`, `in-progress/` and `deprecated/` are not included.

Each skill is a plain folder of editable files. Changes made here stay in this repo and are not
updated automatically. To refresh, copy the newer versions from upstream and bump the commit above.

Run `/setup-matt-pocock-skills` once to write the `docs/agents/*` config the skills read.
