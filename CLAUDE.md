## Agent skills

### Issue tracker

Issues live in GitHub Issues for joshrkay/Nevermore, worked with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The seven default labels, each named after its role: `bug`, `enhancement`, `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` at the root, ADRs in `docs/adr/`. See `docs/agents/domain.md`.

### External peers

`auto`: code-review and jury pick the Claude or Codex adapter from host metadata; models at the CLI default, effort high. See `docs/agents/cross-model.json`.
